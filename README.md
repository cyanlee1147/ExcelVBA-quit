# Excel VBA — 離職業務員自動清理工具

一支 Excel VBA 巨集，將原始保單匯出檔一鍵清理、標記、去重複，省去逐欄逐列手動整理的時間。原本用於離職交接時整理客戶名單的自動化流程。

## 功能

匯入一份 `.xlsx` 後，巨集會自動依序處理：

1. **篩選資料** — 刪除「保單號碼」開頭為特定代碼的列（含去除隱藏字元、全形單引號等資料清洗）
2. **移除欄位** — 刪除「修改日」「修改人」等不需要的欄
3. **重點標色** — 將業務員 / 經手人相關欄位標為黃底
4. **調整結構** — 在指定欄位之間插入空欄，並在最前方新增「承接者」欄
5. **隱私標記** — 將「要保人手機」欄設為紅字提醒
6. **去除重複** — 依手機號碼移除重複資料列

## 技術重點

- 以欄位「標題名稱」動態定位欄號，而非寫死欄號，提高對不同來源檔案的適應性
- `Scripting.Dictionary` 物件做去重複與欄位對應
- 由下往上反向迴圈刪列（避免刪除時索引位移的常見錯誤）
- `Trim` / `Replace` / `Chr(160)` 處理常見的髒資料（空白、隱藏字元、全形符號）
- **集中錯誤處理**：`On Error GoTo` 搭配還原區塊，發生例外時仍會把 `ScreenUpdating`、`Calculation`、`EnableEvents` 還原，避免 Excel 卡在停用狀態
- **效能優化**：處理期間關閉螢幕更新與自動計算
- 邏輯拆分為主程序 + 輔助函式 `尋找欄位`，符合 DRY 原則、方便維護

## 開發紀錄

- 重構時修正了一個原始版本的 bug：`Select Case` 只會執行第一個符合的分支，導致關鍵欄位 `經手人`、`經手人ID` 的位置永遠抓不到、插入空欄的步驟實際從未生效。改以獨立的欄位查找函式解決。

## 使用方式

1. 開啟 `離職文件.xlsm`，啟用巨集
2. 執行 `匯入並處理新檔案_獨立開啟`
3. 在對話框選擇要處理的 `.xlsx` 檔
4. 程式自動完成清理並跳出完成提示

> 原始程式碼見 [`匯入並處理業務資料.bas`](./匯入並處理業務資料.bas)
